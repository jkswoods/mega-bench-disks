# Contributing

Runtime changes target `hytale0.7`; player-guide changes target `docs`. Discuss substantial changes in an issue first. Keep item IDs, disk identities and world-owned contents compatible. Test transfers, upgrades, crafting cancellation and normal save/reload before proposing inventory changes. Multiplayer checks require two actual clients.

Supply your own officially obtained Hytale SDK and the required Mega Bench dependency. Do not commit game binaries, saves, credentials or extracted stock assets. The maintainer reviews contributions before merging or releasing. Release workflows are manual and publish immutable, Hytale-qualified tags.
