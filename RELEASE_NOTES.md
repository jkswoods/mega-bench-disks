First experimental Alpha of Mega Bench: Disks.

- Memorite, recursive 1K/4K/16K/64K disks and safe filled-disk upgrades.
- Eight-bay Drive Racks; up to sixteen owned face-connected racks, including vertical stacks.
- Searchable pooled storage with distinct native Storage/inventory panes and drag/Shift-click transfers.
- Native Mega Bench crafting from stored ingredients; disk identity and contents survive normal save/reload.

Requires Hytale >=0.7.4 <0.8.0 and Mega Bench >=0.3.0 <0.4.0 with companion API1. Native single-player checks used Hytale 0.7.5. The CurseForge 0.7 tag describes the family, not proof of every patch. Install one compatible JAR of each mod with the game/server stopped. Mega Bench 0.2.1 is incompatible.

Experimental preview: actual two-client ownership/concurrency, optional Backpack and human visual/listening checks remain pending. Test on a disposable world and back up world/player data before updates. Storage is owner-only; no cables, chest adapters or remote access. Pre-stable updates may change recipes, balance, behaviour or saved data. Contents belong to the world; transfer the whole save/player data when moving machines.
