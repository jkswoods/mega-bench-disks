# Troubleshooting

**No Open storage button:** check that both compatible mods loaded and a Drive Rack touches the bench's front/back long edge. Mega Bench 0.2.1 lacks companion API1. Remove duplicate older mod copies with the game stopped.

**Zero capacity or missing items:** confirm a disk is mounted and every rack has a face-connected path to the bench. Check the 16-rack limit and ownership. Reconnect disconnected racks; do not delete ledger/save files.

**Disk is refused:** cartridges belong to a world and owner. A copied or foreign cartridge cannot claim the same disk contents. Restore the matching world/player backup rather than manufacturing replacements.

**Transfers or disk changes refuse:** finish or cancel the native craft. Make inventory room. Only amounts that fit transfer; metadata variants may occupy separate browser entries.

**Can't break a rack:** eject every disk and end any active craft. An empty rack used as a crafting bridge is also protected.

**No Memorite nearby:** explore newly generated default home-world terrain underground with an iron pickaxe. Existing terrain is preserved. Custom world generators are not covered by the default generation route.

For a bug report, include your exact Hytale patch, both mod versions and reproduction steps on [GitHub Issues](https://github.com/jkswoods/mega-bench-disks/issues). Remove personal data from screenshots/logs before sharing. Keep an untouched backup if stored items are affected.
